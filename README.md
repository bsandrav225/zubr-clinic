# Клиника «Зубр»

Сайт на PHP + MySQL. Запуск через XAMPP.

1) Скопируйте проект в C:\xampp\htdocs\zubr
2) Запустите Apache и MySQL
3) В phpMyAdmin создайте базу zubr_clinic и импортируйте zubr_clinic.sql
4) Откройте http://localhost/zubr/
5) Админка: http://localhost/zubr/zubr-site-v2/admin/
6) Логин admin, пароль zubr2026.

Если папка называется иначе, адрес менять не нужно — он определяется сам. Свои данные БД можно прописать в zubr-site-v2/config/config.php (образец: zubr-site-v2/config/config.example.php). Файл создаётся из образца при первом запуске.
